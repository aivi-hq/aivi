Under the hood

OpenCode is the runtime. aivi is the shift around it.

OpenCode owns sessions, models, tools and permissions. aivi keeps those sessions reachable from your day: search, schedules, chat, boards and memory. Channels, trackers and forges are plugins, so a fresh install is small and every integration is opt-in. The agents stay ordinary OpenCode agents, and you can always open the same work by hand.

Get started

One install, then one command.

You need Node 26.12 or newer and a macOS or Linux machine that can stay awake. Setup creates the server, seeds the agents and can install it as a background service.

  1. Install the CLI and run setup. It asks whether this machine creates a server or connects to one.
  2. Take the background service if the machine stays on. Otherwise run aivi serve in a terminal.
  3. Add a project or a chat channel when you are ready. The first five minutes guide covers both.

Search runs locally. Your documents stay in their own directories, and the index lives in the aivi home.

Open the first five minutes 
# install the command line
npm i -g @aivi/cli

# create the server or sign in to one
aivi setup

# keep it running in the foreground
aivi serve

Setup can install the same server as a background service, so this last line becomes optional.
