Documentation

Install aivi, connect a project, and keep the server running.

Everything you need to run aivi on a machine you control, from the first install to the jobs that run overnight. The pages are written for the operator, not for someone reading the source code.

  1. Getting started Install aivi, create a server, and check that it answers.
  2. Ways to use aivi One server can be a team's shared memory, a private assistant, and a colleague who owns work.
  3. Projects and tickets How aivi stores a project, maps a board to lanes, and works a ticket without touching the clean checkout.
  4. Chat and knowledge Connect Discord or Slack, learn the chat commands, and shape the index aivi answers from.
  5. Jobs and memory Schedule work, read the run history, and let dreaming keep the memory tidy.
  6. Running aivi Keep the server healthy, read its logs, update it, and back up the home.

Looking for the full reference? The repository holds the detailed chapters on operations, configuration, architecture, and every plugin.
